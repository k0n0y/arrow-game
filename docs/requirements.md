# 正式要求核对表

来源：用户提供的正式作业页面截图（共 6 张），2026-09-16。
正式地址：https://edu.cnblogs.com/campus/fzu/2026-01SoftwareEngineeringandSoftwareEngineeringPractice/homework/16718

只参考基础单格箭头玩法，不复制其他同学的项目、商业游戏素材或关卡。

| 编号 | 要求 | 实现与验收计划 |
|---|---|---|
| R01 | Python 图形界面、开始/游戏/结果页面 | pygame-ce，自绘界面，鼠标交互 |
| R02 | 上下左右四方向箭头 | U/D/L/R，图形线段绘制 |
| R03 | 检测整条行/列路径直到边界 | 独立纯逻辑模块，四方向及远距离障碍测试 |
| R04 | 畅通飞出、阻挡保留并反馈 | 飞出动画、碰撞晃动和红色提示 |
| R05 | 失误扣减并显示、用尽失败 | 每关 3 次，失败后阻止棋盘操作 |
| R06 | 至少 3 个可解关卡 | 4×4、5×5、6×6；解序列与自动验证 |
| R07 | 清空通关、下一关、全部完成 | 显式状态机与流程测试 |
| R08 | 重开恢复当前关卡和失误数 | 深复制关卡模板，T06 测试 |
| R09 | 至少 3 次真实 AIGC 记录 | 开发中逐阶段记录，不编造人工修改 |
| R10 | GitHub、README、多次有意义提交 | 本地分阶段提交，远端发布单独核验 |
| R11 | T01—T06 测试与结果 | 规则测试、状态测试和 pygame 事件测试 |
| R12 | 博客首表与七项正文 | 项目展示、简介、实现、AIGC、测试、PSP、心得 |
| R13 | 本人实际试玩所有关卡 | 提供试玩清单；自动化不代替本人试玩 |

附加功能按需要实现：关卡选择、提示、计时、Windows 可执行文件。
不宣称扩展功能必然获得加分。

## 提交边界

截图明确要求本人理解代码并试玩。AI 可以实现和验证程序，但不能代填个人体验、个人实际耗时或假称已发布到 GitHub/博客园。
